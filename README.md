# Electric-Vehicle-Sales-Business-Analytics-Dashboard
Electric vehicle sales analysis using Python, Pandas, Excel, and Power BI with an interactive business analytics dashboard.

An end-to-end Business Analytics project focused on analyzing Electric Vehicle (EV) sales data using **Python, Pandas, Excel, and Power BI**.

The project covers data cleaning and preprocessing, exploratory analysis, business KPI calculation, visualization, and the development of an interactive Power BI dashboard to identify sales and profitability trends.

## 🎯 Project Objective

The objective of this project is to analyze EV sales data and identify meaningful business insights related to:

- Sales and revenue performance
- Profitability
- Year-wise EV sales growth
- Regional and state-wise performance
- Battery-type sales distribution
- Key business KPIs
